ANN forward pass

Neuron fill intensity = activation magnitude. Green = positive, red = negative. Edge thickness = weight magnitude, color = sign. Hover a neuron for details.
Hidden layer 1 · Linear(40→96) → ReLU
h₁ = ReLU( W₁ · x̂ + b₁ )
Each of 96 hidden units computes a weighted sum of all 40 scaled inputs plus a bias. ReLU zeroes negative pre-activations — dead cells are flagged in red. Typical healthy ReLU layer runs 30–60% zero; much higher and capacity is wasted.
